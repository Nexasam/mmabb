## 📞 Need to Change Images?

### To Replace an Image:
1. Find a new image on Unsplash.com
2. Copy the image URL
3. Update the `src` attribute in the code
4. Rebuild: `npm run build`
5. Refresh browser

### Image URL Format:
```
https://images.unsplash.com/photo-[ID]?w=[width]&h=[height]&fit=crop&q=80
```

Example:
```jsx
<img 
    src="https://images.unsplash.com/photo-1576765608535-5f04d1e3f289?w=1200&h=900&fit=crop&q=80" 
    alt="Descriptive alt text here"
    className="h-full w-full object-cover"
/>
```
